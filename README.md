# 马赛克 Mosaic

一个基于 Web 的马赛克（Mosaic）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5211/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 数字表示以它为中心的 3×3 区域内黑格总数，包含数字格自身
- 所有数字必须同时满足
- 规则有两种变体（题目用可选字段 `mode` 区分，缺省为严格版）：

| 变体 | 数字格自身 | 数字范围 | 适用 |
|------|-----------|---------|------|
| `strict`（严格版，默认） | 不能涂黑 | 0–8 | 内置 6 道旧题 |
| `standard`（标准 Mosaic） | 可以是黑格 | 0–9 | 图片导入的标准题面 |

> 严格版等价于「数字统计周围 8 格」；标准版才允许数字格自身是黑格（所以会出现 9）。
> 旧题没有 `mode` 字段，一律按严格版解释，行为与以前完全一致。

## 逻辑定式（逻辑解题规则）

`src/game/rules.ts` 的规则引擎只做**可证明**的局部推理（做到不动点），不做猜测；
猜不出来的部分才交给 `solver.ts` 的回溯兜底（大棋盘走 SAT）。当前实现三条规则：

| 规则 | 内容 |
|------|------|
| 规则 1 | `strict` 变体：数字格自身不能涂黑（`standard` 变体跳过此条） |
| 规则 2 | 单窗口计数：`need = 数字 − 窗口内已确定黑格数`；`need = 0` → 窗口内未知格全是白格；`need = 未知格数` → 窗口内未知格全是黑格；`need` 越界 → 矛盾 |
| 规则 3 | **相邻窗口重叠差分**：设 A、B 为两个数字窗口的未知格集合，a、b 为它们还差的黑格数，U = A\B，V = B\A，d = a − b。由 `sum(U) − sum(V) = d` 及 `0 ≤ sum(U) ≤ |U|`、`0 ≤ sum(V) ≤ |V|`：`d > |U|` 或 `d < −|V|` → 矛盾；`d = |U|` → U 全为黑格、V 全为白格；`d = −|V|` → V 全为黑格、U 全为白格 |

规则 3 的几何含义就是「两个数字窗口重叠时，非重叠区的黑格数被两个窗口计数的差唯一决定」：

- 水平 / 垂直相邻的两个窗口，非重叠区分别是各自的 3 格（边框处 2 格、角落 1 格）边条；
- 窗口候选集互相包含（U 或 V 为空）时退化为「窗口包含」差分；
- 边框 / 角落窗口被题板裁掉后只剩 2~4 格，规则 2 + 规则 3 即可完成这类强制；
- 局部 2×2 / 3×3 窗口组合（两个窗口错位一格、两格）都由规则 3 统一处理。

> 题面只提供窗口数字，没有提供总黑格数或行列黑格数，因此**没有**可用的
> 「全局计数上下界」约束；规则 3 里 `d` 与 `|U|`、`|V|` 的比较就是局部计数的整数上下界推理。

`npm run check` 基线（加入定式前）：6 题中 4 题需回溯；加入定式后：5 题「逻辑可推满」，
`mosaic-8x8-lgdpmu` 仍需 1 次回溯兜底（节点 135 → 25），属于需要反证 / 猜测的难题。

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 黑 → 白标记 → 空 |
| 右键点格 | 反向循环 / 清除 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎（单窗口计数 / 相邻窗口重叠差分）逐帧回放，显示每一步理由；规则推不满时自动用回溯求解兜底；回放中按钮变为停止，按 `P` 暂停/继续。回放从**当前盘面**继续推理：玩家已涂黑的格子视为已知信息，每一帧的 `from` 取当前值，不会覆盖已填内容
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **大棋盘求解**：超过 12×12 的棋盘自动改用 CDCL SAT 求解（`src/game/sat.ts`），
  50×50 图片导入题也能在 1 秒内求出唯一解
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      推理规则
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解（大棋盘走 SAT）
    sat.ts                        CDCL SAT 求解器 + 基数约束编码（50×50 用）
    puzzles.ts / puzzles-data.ts  题库加载与静态题库
    imported-puzzles.ts           图片导入的题目（npm run gen 不会覆盖）
scripts/
  import-image.mjs                图片识图导入题库
```

## 从图片导入题库（识图）

`scripts/import-image.mjs` 用 Playwright + Edge 全自动识别马赛克题面图片（0–9 线索数字），
默认**只预览**，加 `--append` 才写入 `src/game/imported-puzzles.ts`（该文件不会被 `npm run gen` 覆盖）。

```bash
npm run import-image -- board.png                 # 预览识别结果（默认标准版规则）
npm run import-image -- board.png --verify        # 预览 + 唯一解校验 + 参考解
npm run import-image -- board.png --append        # 写入题库（写入 mode: 'standard'）
npm run import-image -- board.png --append --verify --name "识图 · 8×8"
npm run import-image -- board.png --mode strict    # 旧规则图片（数字格不能涂黑，0–8）
```

识别流程：按页面底色裁出题板，用「格子底色比格线亮」的亮度投影找等距格线并自动判定 W×H
（截图与印刷风格图片都适用）→ 每格中心裁切 + 自适应二值化 + 多字体模板匹配识别 0–9。

> 规则变体：导入默认 `--mode standard`（标准 Mosaic，数字格自身可为黑格，数字最大 9），
> 写进题库时带 `mode: 'standard'`；旧图用 `--mode strict`（数字格不能涂黑，0–8）。
> 大棋盘（如 50×50）的唯一解校验会自动走 SAT 求解器，通常 1 秒内完成。

常用参数：

| 参数 | 说明 |
|------|------|
| `--size N` | 手动指定边长（自动判定失败时） |
| `--mode strict\|standard` | 规则变体（默认 standard） |
| `--map "x,y=数字,..."` | 人工修正某格线索，坐标 0 基（列,行），`.` = 无数字 |
| `--ink-drop N` | 数字墨迹相对格子底色的亮度差阈值（默认 60） |
| `--crop "x,y,w,h"` | 只识别图片中的这块区域（截图带页面边框时用） |
| `--json out.json` | 导出识别结果（board / solution / 规则变体 / 是否唯一） |
| `--verify` | 调项目 solver 检查唯一解并求参考解（超时只告警） |
| `--append` | 写入 `src/game/imported-puzzles.ts`（配合 `--dry` 可只演练不写） |
| `--dry` | 不写入 |

```bash
npm run dev       # 开发服务

npm run audit     # 逐题审计逻辑解题
```
